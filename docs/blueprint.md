# **App Name**: Bienvenue Board

## Core Features:

- Welcome Title: Display a welcoming title on the page.
- Introduction Message: Include a brief, friendly introduction message.
- AI-Powered Quote: Provide a "daily quote" section, with quote content generated by an AI tool.
- Background Styling: Display a visually appealing background.
- Theme Switcher: Offer a customizable theme option (light/dark mode).

## Style Guidelines:

- Primary color: Deep purple (#673AB7), evoking a sense of calm and sophistication.
- Background color: Light gray (#F5F5F5), providing a neutral and clean backdrop.
- Accent color: Soft lavender (#D1C4E9), adding a gentle highlight.
- Body font: 'Inter' (sans-serif) for a modern and readable interface.
- Headline font: 'Space Grotesk' (sans-serif) for headings
- Use simple and elegant line icons for interactive elements.
- Maintain a clean and spacious layout for easy readability.
- Implement subtle fade-in animations for the welcome elements.
